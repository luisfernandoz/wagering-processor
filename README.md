# Wagering Processor

Serviço financeiro distribuído de alta concorrência projetado para processamento de transações de apostas (Wagering), desenvolvido em **NestJS** com **TypeScript estrito**, **MikroORM / PostgreSQL** e **Bun**.

---

## 🚀 Requisitos e Stack Tecnológica

- **Runtime / Package Manager**: [Bun](https://bun.sh/) 1.x
- **Linguagem**: TypeScript (Strict Mode)
- **Framework**: NestJS
- **Banco de Dados**: PostgreSQL
- **ORM**: MikroORM (@mikro-orm/postgresql)

---

## ⚙️ Como Executar o Projeto

### 1. Instalação de Dependências

```bash
bun install
```
